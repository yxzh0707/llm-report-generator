# Reuse and release status

The dissertation project source is publicly available for inspection. The author
has not granted an open-source licence.

The existing internal agent runtime is a separately obtained dependency. A recorded
internal-use permission does not establish public redistribution permission. Its source
archives are excluded here. Native Hermes is not vendored. The InFoBench upstream
evaluation file and upstream README are omitted; retained adaptation metadata and
scripts identify that historical supplementary evaluation. This is not a reproduction
of the official InFoBench benchmark.

Third-party release full texts, PDFs, source snapshots and raw model/operational
records are omitted. Source URLs and the author's compact result decisions remain.
No credentials or private model-service endpoint are included. All dependencies retain
their respective licences and service conditions.
